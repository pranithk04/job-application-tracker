# Job Application Tracker 💼🤖

A full-stack job application tracking platform with automated data persistence, real-time analytics, and AI-powered skill extraction.

## 🚀 Key Features
- **Full-Stack CRUD:** Manage applications, interview stages, and response statuses with Spring Boot and PostgreSQL.
- **AI Skill Parsing:** Integrates Groq AI API to automatically parse job descriptions and highlight required technical skills.
- **Interactive Dashboard:** Dynamic visual tracking built with React.js and Bootstrap UI.

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, REST APIs
- **Frontend:** React.js, JavaScript, Bootstrap
- **Database:** PostgreSQL
- **AI Integration:** Groq AI API

## 💻 Setup & Running Locally

```bash
# 1. Clone the repository
git clone [https://github.com/pranithk04/job-application-tracker.git](https://github.com/pranithk04/job-application-tracker.git)

# 2. Run Spring Boot Backend
cd backend
./mvnw spring-boot:run

# 3. Run React Frontend
cd frontend
npm install
npm start
